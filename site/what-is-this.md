# What is this?

Also why did I do this? Simple answer to that is that, I really have developed some pent up energy after having so long procrastinating to build this website.

More so, a lesson to throw all of that overthinking away, and just do it. Nicecieties could come later, what's important is that it works, and you have fun!

Thus born this blog!

## How does this blog works?

It's so simple I could just write it down on few steps instead of adding a flowchart!

1. The blog get request
2. It search if there's any markdown file named the path or "main" if there's no path
3. It renders the markdown, put it into the html template
4. Shoot it back your way!

Could I just implemented a static compile? Sure, but again it won't be finished within 2h without any AI help and all the setup in the VM too!
